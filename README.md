# Budget Hub

A personal finance management app built with Angular 20+.

## Quick Start

```bash
npm install
npm start
```

## Tech Stack

- Angular 20.3.0 (Standalone Components)
- TypeScript 5.9.2
- Tailwind CSS (CDN)
- Angular Signals

## Available Commands

- `npm start` - Start development server
- `npm run build` - Build for production
- `npm test` - Run tests

## Modules

- **Dashboard** - Financial overview
- **Transactions** - Track income and expenses
- **Budgets** - Manage budgets
- **Settings** - User preferences
